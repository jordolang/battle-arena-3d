# Battle Arena 3D

An open-field, Mortal Kombat style last-one-standing brawler in Three.js for 2 to 8 fighters.
Up to four people share one keyboard and CPU fighters fill the other seats.

- `index.html` is the whole game in one file. Open it in a browser, or serve the repo as a static site.
- `source/` holds the readable source; `source/README.md` explains controls, moves, online rooms and how to rebuild.
